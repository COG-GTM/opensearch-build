## Decision rules

* **port**: the pipeline is live and gets a GitHub Actions workflow. Phase follows the board plan: **p3** = automation, docker, validation and AMI jobs (s3.1–s3.5); **p4** = distribution builds, tests, scheduled builds and benchmarks (s4.1–s4.5); **p5** = release workflows (s5.1–s5.4). Workflow names are targets for those tickets; a ticket may rename a file but must update this table.
* **retire**: not ported. Default for everything under `jenkins/legacy/`, unless an active Groovy test or a non-legacy pipeline still references it. Checked: `grep -rn "jenkins/legacy" tests/jenkins` finds only `TestSignStandaloneArtifactsJob.groovy` (active), so `sign-standalone-artifacts` is the one legacy file ported. `TestDataPrepperReleaseArtifacts` and `TestMavenSignReleaseJob` are `@Ignore` and load paths that no longer exist. No non-legacy `build job:` (directly or through a library step) targets a job name that only a legacy file defines.
* Nothing under `jenkins/` is deleted before the final cutover ticket (s6.3).
